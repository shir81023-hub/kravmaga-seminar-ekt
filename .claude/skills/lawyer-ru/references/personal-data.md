# Персональные данные (152-ФЗ)

Применяется ко всем, кто собирает ПДн граждан РФ, включая сайты с формами
записи/обратной связи.

## Базовые требования к оператору

1. **Правовое основание** обработки (ст. 6 152-ФЗ): чаще всего — согласие
   субъекта или исполнение договора с ним.
2. **Политика обработки ПДн** — публичный документ, размещённый на сайте
   (ст. 18.1). Обязательна, если есть сбор данных через сайт.
3. **Согласие на обработку ПДн** — отдельно и явно. Для рекламной рассылки
   и передачи третьим лицам нужно отдельное согласие.
4. **Уведомление Роскомнадзора** об обработке ПДн (ст. 22) — по общему
   правилу требуется до начала обработки.
5. **Локализация** (242-ФЗ): первичный сбор и хранение ПДн граждан РФ — на
   серверах в РФ.
6. **Меры защиты** ПДн (ст. 18.1, 19).

## Согласие на обработку ПДн — обязательные элементы

- ФИО, адрес субъекта (или способ его идентификации).
- Наименование/ФИО и адрес **оператора**.
- Цель обработки.
- Перечень обрабатываемых ПДн.
- Перечень действий с ПДн и способы обработки.
- Срок действия согласия и порядок его **отзыва**.
- Подпись/акцепт субъекта.

Для сайтов согласие оформляется чекбоксом (не предзаполненным) рядом с
формой + ссылкой на Политику.

## Минимальный набор для лендинга с формой записи

1. Чекбокс «Я согласен на обработку персональных данных» (без галочки по
   умолчанию).
2. Ссылка на **Политику обработки персональных данных**.
3. Сбор только необходимых данных (имя, телефон/e-mail — для связи).
4. Указание цели: «обработка заявки и связь по записи на мероприятие».

## Ответственность

Нарушения ПДн — ст. 13.11 КоАП РФ. Штрафы существенно ужесточены
(вплоть до оборотных за утечки) — сверяй актуальные размеры, они менялись.

## Шаблон-заготовка согласия (плейсхолдеры)

```
СОГЛАСИЕ на обработку персональных данных

Я, [ФИО], предоставляю [Наименование/ИП/ФИО оператора], [адрес],
ИНН [___], согласие на обработку моих персональных данных: [перечень —
ФИО, номер телефона, адрес электронной почты] с целью [обработки заявки
и связи по записи на мероприятие «[название]»].

Обработка включает: сбор, запись, систематизацию, хранение, уточнение,
использование, передачу [кому, если есть], удаление.

Согласие действует [срок / до отзыва]. Я вправе отозвать согласие,
направив заявление по адресу [___] / на e-mail [___].

[Дата]   [Подпись/акцепт]
```

⚠️ Это заготовка; финальный текст и факт уведомления РКН должен проверить
юрист с учётом реальных процессов оператора.
