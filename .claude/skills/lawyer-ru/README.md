# Скилл `lawyer-ru` — юрист для физических лиц (право РФ)

Самостоятельный скилл-ассистент для Claude Code, который помогает
**гражданину** понять и защитить свои права по законодательству Российской
Федерации: как потребителя, работника, в семейных, жилищных и
наследственных вопросах, как субъекта персональных данных, а также при
составлении претензий, жалоб и исков.

Скилл не привязан к какому-либо проекту и работает в любом репозитории.

## Установка

Скилл лежит в `.claude/skills/lawyer-ru/` — Claude Code подхватит его
автоматически в этом проекте.

Чтобы поставить глобально (для всех проектов):

```bash
cp -r .claude/skills/lawyer-ru ~/.claude/skills/
```

## Использование

Опиши ситуацию на русском, например:
- «Магазин отказывается возвращать деньги за бракованный товар — что делать?»
- «Работодатель не отдаёт расчёт при увольнении»
- «Как отозвать согласие на обработку персональных данных?»
- «Как делится квартира при разводе?»
- «Составь претензию продавцу» / «Помоги с исковым заявлением»

Claude активирует скилл по описанию из `SKILL.md`.

## Структура

```
lawyer-ru/
├── SKILL.md                 # ядро: юрист для физических лиц
├── README.md                # этот файл
└── references/
    ├── codes.md             # карта кодексов и ФЗ РФ
    ├── consumer.md          # права потребителя (ЗоЗПП)
    ├── labor.md             # трудовые права работника (ТК РФ)
    ├── family.md            # семья, развод, алименты, наследство
    ├── housing.md           # жилищные права (ЖК РФ)
    ├── personal-data.md     # права субъекта ПДн (152-ФЗ)
    ├── contracts.md         # договоры с участием гражданина
    └── claims.md            # претензии, жалобы, иски + шаблоны
```

## Важно

Скилл даёт информацию общего характера и черновики документов, а не
юридическую консультацию. Проверяйте актуальную редакцию норм и сроки;
при серьёзных рисках обращайтесь к практикующему юристу.
