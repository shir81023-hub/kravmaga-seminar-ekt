# Скилл `lawyer-ru` — юрист (право РФ)

Скилл-ассистент для Claude Code с акцентом на законодательстве Российской
Федерации: договоры, оферты, персональные данные (152-ФЗ), защита прав
потребителей, отказ от претензий для спортивных мероприятий и разъяснение
норм кодексов РФ.

## Установка

Скилл уже лежит в `.claude/skills/lawyer-ru/` этого репозитория, поэтому
Claude Code подхватит его автоматически в этом проекте.

Чтобы поставить глобально (для всех проектов), скопируй папку:

```bash
cp -r .claude/skills/lawyer-ru ~/.claude/skills/
```

## Использование

Просто опиши задачу на русском, например:
- «Составь публичную оферту на семинар по крав-мага»
- «Подготовь согласие на обработку персональных данных для формы записи»
- «Проверь договор оказания услуг с точки зрения ЗоЗПП»
- «Сделай расписку об ознакомлении с рисками для участников тренировки»

Claude активирует скилл по описанию из `SKILL.md`.

## Структура

```
lawyer-ru/
├── SKILL.md                     # основной скилл (frontmatter + инструкции)
├── README.md                    # этот файл
└── references/
    ├── codes.md                 # карта кодексов и ФЗ РФ
    ├── contracts.md             # договорная работа, существенные условия
    ├── personal-data.md         # 152-ФЗ, согласие и политика ПДн
    ├── consumer.md              # защита прав потребителей (ЗоЗПП)
    └── waiver.md                # отказ от претензий / риски (спорт)
```

## Важно

Скилл готовит черновики и даёт информацию общего характера, а не
юридическую консультацию. Перед использованием документов проверяйте
актуальную редакцию норм и при существенных рисках обращайтесь к
практикующему юристу.
